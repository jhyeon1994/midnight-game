# MIDNIGHT · 한밤의 밀정

회원가입 없이 초대 코드로 함께하는 **한국어 실시간 멀티플레이 밀정 추리 게임**입니다.
프런트 화면만 있는 목업이 아니라 Node.js 서버에서 역할·타이머·행동·투표·승패를 처리하는 실행 가능한 프로젝트입니다.

## 1. 가장 빠르게 실행하기

필요: **Node.js 22 이상**, npm. 최초 패키지 설치에는 인터넷이 필요합니다.

압축을 풀고 그 폴더에서 터미널을 열어 다음 명령을 실행합니다.

```bash
npm ci
npm start
```

브라우저에서 **http://localhost:3000** 을 여세요. 종료는 터미널에서 `Ctrl+C`입니다.

- Windows: Node.js 설치 후 `START-WINDOWS.bat`을 실행할 수도 있습니다.
- macOS/Linux: `sh start.sh`를 사용할 수 있습니다.
- `public/index.html`을 더블 클릭해 여는 방식으로는 작동하지 않습니다. 실시간 서버가 필요합니다.
- 설치가 실패하면 Node.js 버전과 네트워크를 확인하세요. `node -v`로 버전을 확인할 수 있습니다.
- 3000 포트를 다른 프로그램이 사용 중이면 macOS/Linux에서는 `PORT=3001 npm start`, PowerShell에서는 `$env:PORT=3001; npm start`로 실행하세요.

## 2. 친구들과 접속하기

### 같은 PC에서 테스트

다른 브라우저 탭이나 시크릿 창으로 같은 주소를 여세요. **각 탭은 별개의 참가자**입니다.
방을 만든 뒤 6자리 코드를 전달하거나 초대 링크를 복사하세요. 각자 닉네임을 입력하고 준비 완료를 누르면 방장이 시작합니다.

### 같은 Wi-Fi의 다른 기기

서버를 실행한 PC의 **로컬 IP 주소**를 확인하세요. 예를 들어 IP가 `192.168.0.10`이라면 친구는 `http://192.168.0.10:3000`으로 접속합니다.
PC 방화벽에서 해당 포트를 허용해야 할 수 있고, 공유기의 기기 간 통신 차단이 해제되어 있어야 합니다.

**중요:** `localhost`는 접속하는 기기 자신을 뜻합니다. 친구에게 `localhost` 초대 링크를 보내면 친구의 PC를 찾습니다.
다른 기기에서 접속 가능한 IP 주소로 먼저 사이트를 연 뒤 초대 링크를 복사하세요.
WSL·컨테이너에서 직접 실행하면 호스트 포트 전달과 방화벽 설정이 추가로 필요할 수 있습니다.

### 서로 다른 인터넷에서 접속

공개 HTTPS 주소를 가진 **지속 실행 가능한 Node.js/Docker 서버**에 배포해야 합니다. 이 프로젝트는 공개 인터넷에 배포되어 있지 않습니다.
사용자 계정·도메인·결제 설정을 임의로 만들거나 연결하지 않았습니다.

일반적인 배포 설정:

- 빌드/설치: `npm ci --omit=dev`
- 시작 명령: `npm start`
- 환경 변수: `PORT`(호스팅 서비스가 지정하는 값, 기본 3000)
- 상태 점검: `GET /health`
- 프로세스: **단일 인스턴스**
- WebSocket 및 HTTP long-polling 연결을 지원해야 합니다.
- 정적 파일 전용 호스팅이나 요청마다 종료되는 서버리스 함수에 그대로 올리면 안 됩니다.
- HTTPS를 적용하고 프록시에서 WebSocket Upgrade를 허용하세요.

Docker가 있는 환경에서는:

```bash
docker build -t midnight-mafia .
docker run --rm -p 3000:3000 --name midnight-mafia midnight-mafia
```

Dockerfile은 포함되어 있지만 이 제작 환경에서 Docker 빌드를 실행하지는 않았습니다. 실제 확인은 Node.js 직접 실행으로 수행했습니다.

Nginx를 이미 운영 중이라면 서버 블록의 location에 다음 설정을 적용할 수 있습니다. 인증서/도메인 설정은 별도입니다.

```nginx
location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_read_timeout 120s;
}
```

## 3. 수정된 게임 규칙

- **5~12명**이 참가합니다. 밀정·친일파·독립군·한국인 의사를 각 **1명**, 나머지는 한국인으로 무작위 배정합니다.
- 독립군 측: 독립군, 한국인 의사, 한국인. 밀정 측: 밀정, 친일파.
- 역할 확인은 8초입니다. 이후 첫날 밤부터 자동 진행합니다.

### 첫날 밤

1. **친일파 확인 시간:** 친일파 본인 화면에만 밀정의 이름이 자동으로 표시됩니다. 별도 선택/확인은 필요 없습니다. 공개 역할 확인 시간에는 아직 알려 주지 않습니다.
2. **독립군 조사 시간:** 자신이 아닌 생존자 한 명의 밀정 여부를 조사합니다. 결과는 아침에 본인에게만 기록됩니다. 친일파를 조사하면 '밀정이 아닙니다'로 표시됩니다.
3. 첫날 밤에는 밀정 공격과 의사 보호가 없습니다.

밀정에게 친일파의 신원을 알려 주지는 않습니다. 친일파는 이후 밤에 사용할 능력이 없습니다.

### 모든 낮: 토론 5분 → 투표

- 낮 토론은 항상 **300초(5분)**이며 방장도 시간을 바꾸거나 조기 종료할 수 없습니다.
- 앱 내 채팅은 없습니다. 모여서 대화하거나 앱 외부의 통화 수단 등으로 토론하세요. 앱 자체에는 음성 통화 기능도 없습니다.
- 시간이 끝나면 생존자 전원이 밀정으로 의심되는 생존자 한 명을 지목합니다. 플레이어 카드 선택 후 **선택 확정하기**를 누르면 변경할 수 없습니다.
- **밀정을 지목하면 독립군 측 즉시 승리.** 밀정이 아니면 지목된 사람은 탈락합니다. 탈락 후 자동 승리 조건을 먼저 검사하고, 게임이 계속되면 다음 날 밤으로 넘어갑니다.
- **최다 득표 동점이면 동점자만 후보로 재투표**합니다. 모든 생존자의 표를 초기화하고, 후보자가 아닌 생존자도 다시 투표합니다. 재차 동점이면 재투표를 반복합니다.
- 기권 버튼은 없습니다. 미참여 표는 집계에서 제외하고, 표가 하나도 없으면 동일한 후보로 재투표합니다. 동점/미참여가 계속되면 한 명이 정해질 때까지 투표가 계속되며 임의로 탈락시키지 않습니다.
- 자기 자신에게도 투표할 수 있습니다. 재투표의 후보자가 자신의 표를 행사할 수 있도록 한 세부 규칙입니다.
- 모든 생존자가 확정하면 투표는 조기 마감됩니다. 전원이 봇인 엔진 테스트에서는 투표 타이머 종료 시 판정합니다.

### 둘째 밤부터 반복

1. **밀정:** 자신을 제외한 생존자 한 명 공격.
2. **한국인 의사:** 자신을 포함한 생존자 한 명 보호. 연속 보호 제한 없음.
3. **독립군:** 자신을 제외한 생존자 한 명 조사.
4. 모두 행동한 뒤 보호·공격을 판정합니다. 보호받지 못한 공격 대상은 탈락하고 조사 결과는 조사자에게만 전달됩니다. 밤에 공격받은 조사자도 그날의 조사를 수행할 수 있습니다.
5. 승리 조건을 검사한 후 다음 5분 낮 토론으로 넘어갑니다. 이후 같은 밤 순서와 낮을 반복하며 일차는 계속 증가합니다.

각 역할은 **자기 순서에만** 행동할 수 있습니다. 역할이 탈락했거나 미접속이어도 해당 시간은 유지됩니다. 행동을 제출하지 않으면 그날 능력을 쓰지 않습니다.

### 승리 조건과 시간

- **독립군 측:** 밀정을 투표로 지목해 탈락시키면 즉시 승리.
- **밀정 측:** 생존 **밀정＋친일파 수가 나머지 생존자 수 이상**이면 즉시 자동 승리. 탈락한 친일파는 세지 않습니다.
- 예: 5명 시작 시 밀정 측 2명 / 나머지 3명입니다. 첫 투표에서 독립군 측 한 명을 오지목하면 2 대 2가 되어 밀정 측이 즉시 이깁니다.
- 기본 시간: 역할 확인 8초, 밤 **각 역할별** 30초, 낮 300초, 투표/재투표 각 30초. 대기실에서 밤 역할별 시간과 투표 시간만 15/30/45/60초 중 변경할 수 있습니다.
- 탈락한 사람의 역할은 게임 종료 때 공개합니다. 밀정 지목이 맞으면 승리를 선언하고 모든 역할을 공개합니다.
- **모든 채팅을 서버에서 차단**합니다. 대기실·공개·밀정 비밀·탈락자·게임 종료 후 채팅까지 예외가 없습니다. 화면에도 입력창이 없으며 시스템 진행 안내만 표시합니다.

### 혼자 연습하기

첫 화면의 `혼자 먼저 둘러보기`는 본인과 봇 5명의 방을 만듭니다. 방장은 대기실에서 봇을 추가/삭제할 수 있습니다. **봇은 추리 AI가 아닌 무작위 행동 연습용**입니다. 실제 게임과 동일하게 낮 토론 5분을 기다립니다.

## 4. 연결·개인정보·운영 범위

- 재접속 토큰은 해당 브라우저 탭의 `sessionStorage`에만 저장합니다. 같은 탭을 새로고침하거나 일시적으로 네트워크가 끊기면 동일 참가자로 돌아옵니다.
- 토큰은 비밀번호와 같습니다. 브라우저 저장소 내용을 공유하지 마세요. 공유 PC에서는 사용 후 방에서 나가세요.
- 일부 브라우저의 탭 복제는 세션 저장소도 복제할 수 있습니다. 같은 세션이 중복 접속하면 새 연결만 유지합니다. 별도 참가자는 주소를 새 탭에 직접 열거나 시크릿 창을 사용하세요.
- 브라우저 저장소가 차단된 환경에서도 입장은 가능하지만 재접속 복구는 제한됩니다.
- 방장이 끊기면 접속 중인 다른 사람에게 방장을 넘깁니다. 대기실의 끊긴 자리는 방장이 `×`로 정리할 수 있습니다. 정리된 세션은 복구할 수 없습니다.
- 게임 중 연결이 끊긴 사람도 생존자로 유지됩니다. 복귀 전까지 행동하지 않은 것으로 처리되며 타이머는 계속 흐릅니다.
- 진행 중에는 새 참가자가 들어올 수 없습니다. 명시적으로 나가면 세션을 지우므로 그 게임에 복귀할 수 없습니다.
- **방/게임 상태와 시스템 안내는 서버 메모리에만 저장**합니다. 서버 재시작·절전·재배포 시 사라집니다. 진행 안내는 방당 최근 250개까지만 유지합니다. 사용자 채팅은 저장하지 않습니다.
- 전원이 접속을 끊은 방은 약 15~16분 후 정리합니다. 방의 최대 유지 시간은 약 24시간입니다.
- 기본 최대 방 수는 500개입니다. 이는 서버 용량을 보장하는 부하 테스트 수치가 아닙니다.
- 음성 채팅, 계정, 랭킹, 신고/차단, 영구 기록, 데이터베이스, 여러 서버 간 동기화는 포함하지 않습니다.
- 회원가입 없는 초대 코드는 강한 접근 통제가 아닙니다. 닉네임 등에 민감한 개인정보를 넣지 마세요.
- 서버는 역할별 상태를 별도로 전송하고 서버 권한 검증, 채팅 차단, 요청 속도 제한, HTML 이스케이프와 CSP를 적용합니다. **전문 보안 감사나 대규모 DDoS/부하 테스트를 통과한 서비스라는 뜻은 아닙니다.** 공개 대규모 운영에는 IP 단위 제한, 모니터링, 신고/모더레이션 등을 추가해야 합니다.

## 5. 테스트

```bash
npm ci
npm test
```

게임 엔진/네트워크 테스트 23개를 통과했습니다.

- 5~12명 역할 배정, 준비/정원 검증
- 첫날 친일파에게만 밀정 정보 제공, 첫날 공격/보호 불가
- 둘째/셋째 밤 순서, 보호/조사/탈락 판정, 죽은 역할의 시간 유지
- 300초 토론 고정 및 타이머 경계(299,999ms / 300,000ms) — Node 모의 시계 사용
- 오지목 탈락, 동점 후보 제한 재투표, 연속 동점/무투표, 즉시 승리와 생존자 합산
- 전 단계 채팅 차단, 역할·토큰·조사 결과 비공개
- 100개 봇 게임 시뮬레이션
- 실제 Socket.IO 클라이언트 6개: 행동 권한, 채팅 차단, 다른 방 격리, 재접속 시 친일파 정보 복구

선택 사항 — Chromium 브라우저 테스트:

```bash
npx playwright install chromium
npm run test:browser
```

Linux에서는 별도의 Chromium OS 라이브러리가 필요할 수 있습니다. 이 환경에서는 이전 프로젝트의 작업 폴더에만 추출되어 있던 라이브러리를 재사용했으며 시스템 설정을 바꾸지 않았습니다.
브라우저 테스트는 6개 독립 브라우저 참가자와 PC/모바일 크기에서 역할 가이드, 채팅 입력창 제거, 낮 시간 고정 표시, 친일파 정보, 재접속, 순서별 행동, 재투표, 최종 승리 등을 검사합니다. 8초 역할 확인은 실제 타이머로 기다리며 이후 단계는 테스트 코드에서 수동 전환합니다. 전체 5분을 실제로 기다리는 대신 엔진의 모의 시계로 자동 전환 경계를 검증합니다.
실행 결과와 화면 캡처는 `artifacts/`를 참고하세요. iOS Safari·Android 실기기, Docker 빌드, 공개 서버 배포는 검사하지 않았습니다.

```text

public/                한국어 반응형 프런트엔드

  fonts/               로컬 Noto Sans KR + OFL 라이선스
```
